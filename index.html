Getting Shimeji Running

Shimeji is a Java program, so your computer needs Java installed before anything else will work.

Step 1 - Install Java

  1. Go to java.com/download and download Java for your system.
  2. Run the installer and follow the prompts (defaults are fine).
  3. Restart your computer if it asks you to.

Step 2 - Check it worked

Windows: open Command Prompt (search "cmd" in the Start menu) and type:

java -version

macOS: open Terminal (Command+Space, type "Terminal") and type the same command:

java -version

If you see a version number printed back, Java is installed correctly. If you see "command not found" or similar, reinstall Java and make sure you restart your computer.

Step 3 - Download and unzip your Shimeji

  1. Pick a character on this site and click Summon (or the equivalent download button) to get your custom ZIP.
  2. Find the downloaded ZIP file (usually in your Downloads folder).
  3. Right-click it and choose Extract All (Windows) or double-click it (macOS) to unzip it into its own folder.
  4. Keep that folder somewhere permanent - don't leave it in Downloads long-term, since deleting the ZIP folder later will delete your Shimeji.

Step 4 - Run it

Inside the extracted folder, look for Shimeji-ee.jar.

  • Windows: double-click Shimeji-ee.jar. If double-clicking does nothing, right-click it > Open with > Java Platform SE binary.
  • macOS: double-click Shimeji-ee.jar. If macOS blocks it (unidentified developer), right-click > Open, then confirm in the popup.

Your character should pop up on screen and start wandering around!

Nothing happening when you double-click the jar? Open a terminal/command prompt, navigate to the extracted folder (cd followed by the folder path), and run: 
java -jar Shimeji-ee.jar
Any error message that appears will tell you what's missing (usually a Java install or version issue).

Once it's running, check the Shortcut Guide button up top for how to make it launch with a single click next time.

Create a Desktop Shortcut

After you download your custom Shimeji:

Windows

  1. Extract the ZIP to a folder you will keep.
  2. Inside that folder, right-click, choose New > Text Document.
  3. Name it Launch_Shimeji.bat (make sure the extension is .bat).
  4. Right-click > Edit, paste:
    java -jar "Shimeji-ee.jar"
  5. Save. Double-click .bat to launch.
  6. For desktop icon: right-click .bat > Send to > Desktop (create shortcut).

macOS

  1. Extract the ZIP and open the folder.
  2. Open Automator (Command+Space, type Automator).
  3. Choose Application, click Choose.
  4. Add a Run Shell Script action.
  5. Paste:
    cd /path/to/your/extracted/folder
java -jar "Shimeji-ee.jar"
    (Replace with actual path.)
  6. Save to Desktop. Double-click to run.

Tip: Pin the shortcut to your taskbar or dock.
