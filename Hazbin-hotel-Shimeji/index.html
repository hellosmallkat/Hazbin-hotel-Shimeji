🔧 Create a Desktop Shortcut (One‑Click Launch)

After downloading your custom Shimeji from its page:

Windows

  1. Extract the ZIP to a folder you’ll keep.
  2. Inside that folder, right‑click → New → Text Document.
  3. Name it Launch_Shimeji.bat (make sure the extension is .bat, not .txt).
  4. Right‑click the new file → Edit, and paste: 
    java -jar "Shimeji-ee.jar"
  5. Save. Double‑click the .bat to launch.
  6. For a desktop icon: right‑click the .bat → Send to → Desktop (create shortcut).

macOS

  1. Extract the ZIP and open the folder.
  2. Open Automator (Command + Space, type Automator).
  3. Choose Application → Choose.
  4. Add a Run Shell Script action.
  5. In the script field paste: 
    cd /path/to/your/extracted/folder
java -jar "Shimeji-ee.jar"
    (Replace the path with your actual folder.)
  6. Save the Automator app to your Desktop. Double‑click to launch.
